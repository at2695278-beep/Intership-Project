# CodSoft Intership-project

This repository contains a set of frontend web development tasks completed during an internship project. The project focuses on building responsive and visually styled web pages using HTML, CSS, and JavaScript.

## Project Overview

The folder includes three mini web projects:

- Task 1: Portfolio / landing page UI
- Task 2: Responsive webpage design
- Task 3: Calculator application UI with JavaScript logic

## Task Details

### Task 1

- Location: `Task1/`
- Files:
  - `index.html`
  - `style.css`
  - `assets/`
- Description:
  - A modern personal portfolio-style landing page
  - Includes hero section, profile image, navigation, and skill tags
  - Designed with a purple theme and rounded card layout

### Task 2

- Location: `Task2/`
- Files:
  - `index.html`
  - `style.css`
- Description:
  - A second frontend design task with a clean and structured layout
  - Focuses on styling, spacing, and UI composition

### Task 3

- Location: `Task3/`
- Files:
  - `index.html`
  - `script.js`
  - `stylec.css`
- Description:
  - A calculator-style interface
  - Includes buttons for operations like clear, divide, multiply, minus, plus, and equal
  - JavaScript handles calculator functionality

## Technologies Used

- HTML5
- CSS3
- JavaScript
- VS Code
- Browser-based frontend execution

## How to Run

You can open any task directly in a browser:

1. Go to the task folder:
   - `Task1`
   - `Task2`
   - `Task3`

2. For a better development experience, use VS Code with a Live Server extension.

## Notes

- This project is focused on frontend UI design and layout practice.
- Styling is mostly custom CSS with responsive page structures.
- Task 3 includes basic interactive logic through JavaScript.
